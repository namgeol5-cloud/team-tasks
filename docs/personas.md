## MVP 헌장

> **목표** — 로그인 없이 팀 단위로 일감을 공유·추적할 수 있는 최소 기능 제품  
> **제약** — 단일 데이터 구조(localStorage 1 key), 기능 5개 이하, 1일(8h) 안에 코드 완성

### 핵심 기능 (5개)

| # | 기능 | 완료 기준 |
|---|------|-----------|
| F1 | 일감 CRUD | 제목·상태·우선순위·담당자·마감일 입력 후 보드에 즉시 반영 |
| F2 | Kanban 4열 보드 | Todo / In Progress / Review / Done 열로 일감 시각화 |
| F3 | 상태 이동 | 카드 메뉴에서 다른 열로 원클릭 이동 |
| F4 | 팀원 관리 | 팀원 추가·삭제, 삭제 시 해당 일감 담당자 자동 해제 |
| F5 | 필터링 | 제목 검색 + 우선순위·담당자 필터 조합 |

### 범위 밖 (v1 제외)

- 실시간 동기화 / 백엔드 DB
- 댓글·첨부파일
- 알림·이메일
- 권한·로그인
- 드래그 앤 드롭
