## 1. 기능 요건

| ID | 이름 | 설명 | 우선순위 |
|----|------|------|----------|
| F-01 | Kanban 보드 | Todo / In Progress / Review / Done 4열로 일감을 시각화한다. 열마다 일감 수를 표시하고, 마감일 초과 카드는 날짜를 빨간색으로 강조한다. | 필수 |
| F-02 | 일감 CRUD | 제목(필수)·설명·상태·우선순위(긴급/높음/보통/낮음)·담당자·마감일 필드로 일감을 생성·조회·수정·삭제한다. 변경 사항은 보드에 즉시 반영된다. | 필수 |
| F-03 | 상태 이동 | 카드의 컨텍스트 메뉴에서 다른 열로 일감을 원클릭 이동한다. 단계 순서 제약 없이 임의 열로 이동 가능하다. | 필수 |
| F-04 | 팀원 관리 | 팀원을 추가·삭제한다. 팀원 삭제 시 해당 팀원이 배정된 일감의 담당자를 자동으로 미배정 처리한다. | 필수 |
| F-05 | 필터링 | 제목·설명 텍스트 검색과 우선순위·담당자(미배정 포함) 드롭다운 필터를 조합해 원하는 일감만 표시한다. 필터 초기화 버튼으로 전체 보드로 복귀한다. | 필수 |

## 2. 비기능 요건

### 성능

| 항목 | 기준 |
|------|------|
| 초기 로드 | 보드 첫 렌더링 ≤ 1 초 (LCP 기준, 일감 50개 이하 환경) |
| 상호작용 응답 | 일감 추가·수정·이동 후 UI 반영 ≤ 100 ms |

### 보안

| 항목 | 기준 |
|------|------|
| 데이터 저장 | 사용자 입력을 innerHTML에 직접 삽입하지 않는다 (XSS 방지) |
| 민감 정보 | localStorage에 개인식별정보(이름 외)를 저장하지 않는다 |

### 가용성

| 항목 | 기준 |
|------|------|
| 오프라인 동작 | 네트워크 없이 브라우저 단독으로 모든 기능이 작동한다 |
| 데이터 유지 | 브라우저 탭을 닫고 재접속해도 마지막 상태가 복원된다 (localStorage TTL 없음) |

### 접근성

| 항목 | 기준 |
|------|------|
| 키보드 탐색 | 다이얼로그·드롭다운을 키보드(Tab / Enter / Esc)만으로 완전히 조작할 수 있다 |
| 색상 대비 | 우선순위 배지·마감일 텍스트의 전경-배경 대비비 ≥ 4.5 : 1 (WCAG AA) |
